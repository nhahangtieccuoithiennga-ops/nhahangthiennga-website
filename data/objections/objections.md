# Lý do khách từ chối / còn phân vân + cách xử lý

> Điền vào cột **"Cách bạn thường xử lý"**. Cột "Lý do gợi ý" mình đoán trước theo kinh nghiệm ngành tiệc cưới/quán ăn — sửa lại nếu không đúng, thêm dòng nếu có lý do khác bạn hay gặp.

| STT | Lý do khách từ chối/phân vân (gợi ý) | Cách bạn thường xử lý (điền tại đây) |
|---|---|---|
| 1 | Chê giá cao hơn chỗ khác | |
| 2 | Sợ đặt cọc rồi bên mình làm không đúng như tư vấn | |
| 3 | Muốn tự chọn món nhưng sợ tính giá không rõ ràng | |
| 4 | Còn đang so sánh với 1-2 chỗ khác, chưa quyết ngay | |
| 5 | Sợ số lượng bàn/khách mời thay đổi vào phút chót | |
| 6 | Ở xa, ngại việc vận chuyển/di chuyển phục vụ tận nhà | |
| 7 | Từng có trải nghiệm không tốt ở chỗ khác nên còn e ngại chung | |
| 8 | *(Lý do khác bạn hay gặp — tự thêm dòng)* | |

## Ghi chú thêm

- *(Ví dụ: lý do nào khó xử lý nhất, hay lý do nào chỉ cần 1 câu là khách đổi ý ngay...)*
