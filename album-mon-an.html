⚙️ Thiết lập Album tự động từ Google Drive

Chỉ cần làm 1 lần • Miễn phí • Tự động cập nhật khi thêm ảnh mới vào Drive

1
Mở Google Apps Script

Vào script.google.com → Tạo project mới → Đặt tên bất kỳ (ví dụ: "Album Thiện Nga")

2
Dán đoạn code sau vào (xóa code cũ trước)
const FOLDER_ID = '1m8VYdlT_uSWitZDgqGJvj5_Do9cbgstH'; function doGet() { try { const folder = DriveApp.getFolderById(FOLDER_ID); const data = scanFolder(folder, 'Tất cả'); const out = { ok: true, data: data, total: data.length }; return ContentService .createTextOutput(JSON.stringify(out)) .setMimeType(ContentService.MimeType.JSON); } catch(e) { return ContentService .createTextOutput(JSON.stringify({ ok: false, error: e.message })) .setMimeType(ContentService.MimeType.JSON); } } function scanFolder(folder, cat) { const files = []; // Ảnh trong thư mục này const fi = folder.getFiles(); while (fi.hasNext()) { const f = fi.next(); if (f.getMimeType().startsWith('image/')) { files.push({ id: f.getId(), name: f.getName().replace(/\.[^.]+$/, ''), cat: cat }); } } // Ảnh trong thư mục con (tự động tạo danh mục) const si = folder.getFolders(); while (si.hasNext()) { const sub = si.next(); files.push(...scanFolder(sub, sub.getName())); } return files; }
3
Deploy (Triển khai) script

Click Deploy → New deployment → Type: Web app → Execute as: Me → Who has access: Anyone → Click Deploy → Copy đường dẫn URL

4
Dán URL vào đây để kích hoạt ngay

URL được lưu vào trình duyệt. Để cố định vào website, mở file album-mon-an.html và dán URL vào biến SCRIPT_URL.

✅
Mẹo tổ chức danh mục tự động

Tạo thư mục con trong Drive theo tên danh mục (ví dụ: Khai Vị, Món Bò, Lẩu…) và chuyển ảnh vào đó. Album sẽ tự động phân loại.

Thử tìm kiếm từ khác hoặc chọn danh mục khác.
