🔄 Cập nhật trực tiếp từ Google Sheet

⚙️ Kết nối Google Sheet cho Góc Bếp

Chỉ cần làm 1 lần • Miễn phí • Sau đó thêm/xoá/sửa bài viết ngay trong Google Sheet

1
Tạo 1 Google Sheet mới

Vào sheets.google.com → tạo bảng tính trống → đặt tên hàng đầu tiên (dòng tiêu đề) đúng theo thứ tự cột sau:

ABCDEFGH
(để trống)STTNgàyTiêu đềMô tả ngắnNội dungẢnh đại diệnẢnh khác

Mỗi dòng tiếp theo là 1 bài viết. Cột Ảnh đại diện/Ảnh khác điền tên file ảnh (ví dụ: cau-chuyen-tet.jpg) sau khi đã gửi ảnh để thêm vào thư mục assets/goc-bep/, hoặc dán thẳng link ảnh (bắt đầu bằng http). Nhiều ảnh khác cách nhau bằng dấu phẩy.

2
Xuất bản lên web dạng CSV

Vào File → Chia sẻ → Xuất bản lên web (Publish to web) → chọn đúng sheet vừa tạo → định dạng CSV → bấm Xuất bản → sao chép đường dẫn.

3
Dán link CSV vào đây để kích hoạt ngay

Link được lưu trên trình duyệt này. Để cố định cho mọi người xem, gửi link đó lại và nhờ cập nhật biến SHEET_CSV trong file goc-bep.html.
